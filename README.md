# Thinai issues

Public issue tracker for the Thinai domain modeling language, the CLI, the
VS Code extension, and the documentation.

The Thinai source repository is private during the alpha. Documentation and
example models are public:

- Documentation: <https://thinai-lang.github.io/>
- Example models: <https://github.com/thinai-lang/thinai-lang.github.io/tree/main/examples>
- VS Code extension: <https://marketplace.visualstudio.com/items?itemName=thinai-lang.vscode-thinai>
- npm packages: <https://www.npmjs.com/package/thinai-cli> and <https://www.npmjs.com/package/thinai-language>

## What belongs here

- Bug reports for the language, language server, CLI, MCP server, or extension
- Feature requests and language design feedback
- Documentation errors or missing explanations

## What does not belong here

- Security vulnerabilities. Use [private vulnerability reporting](https://github.com/thinai-lang/issues/security/advisories/new) instead.
- Questions that the [documentation](https://thinai-lang.github.io/) already answers.

## A useful bug report

Include the smallest `.tni` model that reproduces the problem, the expected and
actual result, your Thinai version, and your operating system. For editor
issues, include the Thinai output channel contents when available.
